시스템 데이터,
정체를 알고 지웁니다

macOS 저장 공간 설정에서 '시스템 데이터'로만 뭉뚱그려 표시되는 수십 GB 가 실제로 무엇인지 폴더 단위로 보여주고, 그중 지워도 되는 것만 골라줍니다.

무료로 내려받기 소스 코드 보기

macOS 13 이상 · Apple 공증 완료

무엇을 하는가

용량 지도

홈 폴더 전체를 한 번 훑어 어느 폴더가 몇 GB 를 쓰는지, 큰 파일이 어디 있는지 목록으로 만듭니다. 애플이 '시스템 데이터'로 감춘 항목도 그대로 나옵니다.

지워도 되는 것만

휴리스틱으로 추측하지 않습니다. 코드에 적힌 허용 목록에 있는 항목만 후보로 올립니다. 목록에 없으면 아무리 커도 건드리지 않습니다.

지워도 되는지 판정

항목마다 지워도 됨 / 확인 후 / 두는 게 좋음 을 이유와 함께 표시합니다. 다시 만들어지는지, 이게 유일한 사본인지를 같이 봅니다.

중복 파일 찾기

문서·다운로드·사진 폴더에서 내용이 완전히 같은 파일을 SHA-256 으로 찾아냅니다. 남길 사본이 그대로 있는지 지우기 직전에 다시 확인합니다.

휴지통 되돌리기

이 앱이 옮긴 것은 기록에 남습니다. 목록에서 골라 원래 자리로 되돌릴 수 있고, 자리에 다른 파일이 있으면 덮어쓰지 않고 멈춥니다.

가볍습니다

순수 SwiftUI + Foundation. 외부 라이브러리도, 백그라운드 상주 프로세스도, 계정 가입도 없습니다.

지우면 안 되는 것을 지우지 않는 방법

파일을 지우는 앱은 신뢰를 얻는 방법이 하나뿐입니다 — 무엇을 절대 하지 않는지를 코드로 못 박고, 그걸 공개하는 것. 이 앱은 다음이 코드에 박혀 있고 설정으로도 풀 수 없습니다.

  • 문서·사진·바탕화면·iCloud Drive 는 대상에서 원천 차단됩니다.
  • 자격 증명(키체인, SSH 키, .env, 클라우드 토큰)은 삭제 직전 마지막 관문에서 한 번 더 걸러냅니다.
  • .git, 백업, 볼륨 밖 경로, 심볼릭 링크는 어떤 규칙으로도 열 수 없습니다.
  • 기본 처리는 휴지통 이동입니다. 휴지통 이동이 실패해도 완전 삭제로 넘어가지 않습니다.
  • 관리자 권한(sudo)을 요구하지 않습니다. 요구하는 정리 앱은 의심하십시오.
  • 실행 전 목록을 보여주고 확인을 받습니다. 지운 내역은 감사 기록으로 남습니다.

삭제 후보 하나가 실제로 지워지기까지 9개의 관문을 순서대로 통과해야 합니다. 검사할 때 한 번, 지울 때 한 번 — 같은 검사를 두 번 합니다. 자세한 내용은 저장소의 설계 문서에 있습니다.

설치

  1. 위 단추로 MacClean-*.dmg 를 내려받습니다.
  2. DMG 를 열고 MacClean 을 Applications 폴더로 끌어다 놓습니다.
  3. 시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근 에서 MacClean 을 켭니다.

    앱을 처음 열면 이 화면으로 바로 가는 단추가 나옵니다.

  4. 앱을 실행합니다.
전체 디스크 접근이 왜 필요한가요?
macOS 는 이 권한 없이는 ~/Library 의 상당 부분을 아예 안 보이게 가립니다. 오류도 나지 않고 그냥 빈 폴더처럼 보여서, 권한이 없으면 앱이 조용히 절반만 찾습니다. 이 권한으로는 읽기만 합니다. 무엇을 지울지는 화면에서 직접 고릅니다.

Apple Developer ID 로 서명하고 공증(notarization)까지 마쳤습니다. "확인되지 않은 개발자" 경고 없이 바로 열립니다. 내려받은 파일이 온전한지 확인하려면 릴리스에 함께 올라온 .sha256 파일과 비교하세요. 

shasum -a 256 ~/Downloads/MacClean-*.dmg

자주 묻는 것

지웠는데 저장 공간이 안 늘어납니다

Time Machine 이나 macOS 업데이트가 만든 로컬 스냅샷이 지워진 블록을 붙잡고 있어서입니다. 터미널에서 tmutil listlocalsnapshots / 로 확인할 수 있고, 보통 며칠 안에 macOS 가 알아서 지웁니다. 앱의 검사 결과 화면에도 이 안내가 뜹니다.

왜 무료인가요?

제 256GB 맥북에어 용량이 부족해서 만들었습니다. 유료화 계획은 없습니다. 쓸 만했다면 후원 페이지를 한 번 봐주세요.

앱이 제 데이터를 어디로 보내나요?

아무 데도 안 보냅니다. 네트워크는 새 버전 확인 한 가지 용도로만 씁니다 (하루 한 번, GitHub 릴리스의 appcast.json 을 읽습니다). 계정도, 원격 분석도, 광고도 없습니다. 이 웹사이트에도 없습니다. 전체 디스크 접근을 요구하는 앱에서 그런 것들은 선을 넘는 일이라고 봤습니다.
